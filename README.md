## SEO
La Home funciona como página de marca y propuesta global. No intenta apropiarse de todas las keywords.

Arquitectura prevista:
- Home: marca + propuesta general.
- /mudanzas-barcelona/: propietaria principal de “mudanzas Barcelona”.
- Money pages específicas para mudanzas, mini mudanzas, portes, vaciados, precios, calculadora, empresas y Piso Listo.
- Páginas locales con contenido realmente distinto, no clones por municipio.

No se inventan volúmenes, CPC, dificultad, reseñas, certificaciones o datos operativos.

## Calculadora
La fórmula actual es **una simulación de maqueta**. No representa precios reales de Movipiso y deberá sustituirse por las reglas de presupuesto validadas con la operativa real.

## Fotografías

Las nuevas cards usan temporalmente fotografía profesional de Pexels, documentada en `PHOTO-SOURCES.md`, hasta disponer de fotografía propia suficiente.
