# Movipiso · web completa de validación

Incluye Home, servicios, B2B, Piso Listo, precios, Barcelona, legales, calculadoras por servicio y 20 guías SEO local.

## Importante
- Indexación activa en páginas públicas; páginas legales incompletas en `noindex` y fuera del sitemap.
- precios/calculadoras: referencias de mercado, no tarifas finales.
- datos legales y contacto real pendientes.
- las imágenes de blog tienen formato homogéneo 16:9.
- cards móviles usan apilado sticky cuando hay varias.
